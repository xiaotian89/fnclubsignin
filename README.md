# 飞牛论坛签到

MoviePilot V3 插件，每日自动在飞牛论坛打卡领取飞牛币。

## 功能

- 每日定时自动签到，时间可自定义
- 支持随机错峰延迟，避免准点签到
- 签到结果推送微信通知
- 保留最近 30 次签到记录
- 支持远程命令 `/fnclub_sign` 手动签到

## 配置

| 配置项 | 说明 |
| --- | --- |
| 启用插件 | 开关 |
| 用户名 | 飞牛论坛账号 |
| 密码 | 登录密码 |
| 签到时间 | Cron 表达式，默认每日 08:00 |
| 随机错峰秒数 | 签到前随机延迟，0-3600 秒 |
| 结果通知 | 签到完成后是否推送通知 |

## 注意事项

- 飞牛论坛规定不允许插件打卡，异常打卡可能扣除飞牛币，请自行评估风险
- 触发滑块验证时自动跳过，当日需手动打卡一次
- 建议开启随机错峰，避免选择整点
