# 飞牛论坛签到

MoviePilot V3 插件，每天自动帮你在飞牛论坛打卡领飞牛币。

## 功能

- 每天定时自动打卡，时间自己定
- 随机延迟一会儿再打，不用准点卡着点
- 打卡结果推送到微信通知
- 历史记录能看最近30次
- 也能发命令 `/fnclub_sign` 手动打一次

## 配置

| 配置项 | 说明 |
| --- | --- |
| 启用插件 | 开关 |
| 用户名 | 飞牛论坛账号 |
| 密码 | 登录密码 |
| 签到时间 | Cron 表达式，默认每天早上8点 |
| 随机错峰秒数 | 打卡前随机等一会儿，0-3600秒 |
| 结果通知 | 打卡完要不要发通知 |

## 注意

- 飞牛论坛说过不让用插件打卡，异常打卡可能扣飞牛币，自己掂量着用
- 遇到滑块验证会自动跳过，当天手动打一次就行
- 建议开随机错峰，别选整点
