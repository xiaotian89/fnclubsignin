# 飞牛论坛签到 (FnClubSignin)

MoviePilot V3 插件：自动登录飞牛私有云论坛（club.fnnas.com）完成"天天打卡"签到，获取飞牛币奖励。

## 功能

- 每日定时自动签到（Cron 可配置，默认每天 08:00）
- 随机错峰延迟（0-3600 秒），降低固定时间打卡被判定异常的风险
- 账号密码模拟登录（Discuz 标准登录），自动维护 Cookie
- 结果解析：打卡成功 / 今日已打卡 / 需滑块验证
- 签到结果推送到 MoviePilot 通知渠道
- 签到历史记录（最近 30 次），可在插件详情页查看
- 支持远程命令 `/fnclub_sign` 手动签到

## 配置

| 配置项 | 说明 |
| --- | --- |
| 启用插件 | 开关 |
| 用户名 | club.fnnas.com 登录用户名 |
| 密码 | 登录密码 |
| 签到时间 | Cron 表达式，默认 `0 8 * * *` |
| 随机错峰秒数 | 0-3600，执行前随机等待 |
| 结果通知 | 是否推送签到结果 |

## 注意事项

- 飞牛社区"天天打卡"规则明确：**请勿使用插件打卡，异常打卡经核实将扣除飞牛币**。
- 若打卡触发滑块验证（真人验证），插件会记录"需要滑块验证"，当天需手动打卡一次。
- 建议开启随机错峰并选择非整点时间，降低异常判定风险。
